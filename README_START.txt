Как запустить
=============

1. Распакуй папку проекта в любое место.
2. Если в папке есть NevernessFishingBot.exe, запусти его и подтверди запрос администратора.
3. Если запускаешь исходники, запусти run_gui.bat двойным кликом: он сам создаст .venv и установит нужные библиотеки.
4. Если Python не установлен, откроется страница скачивания Python. Установи Python 3.10+ с галочкой "Add python.exe to PATH", потом снова запусти run_gui.bat.
5. В GUI открой "Калибровка" и подгони область так, чтобы в preview была только горизонтальная полоса мини-игры.
6. При необходимости нажми "Снимок", выбери "Жёлтая линия" или "Бирюзовая цель", кликни по нужному цвету и двигай допуск, пока красная маска покрывает только нужную деталь.
7. Когда полоса мини-игры видна, нажми "Автонастройка", затем "Старт".

Важно
=====

- run_gui.bat сам перезапускается от имени администратора, поэтому вручную выбирать "Запуск от имени администратора" не нужно.
- Первый запуск требует интернет для установки библиотек.
- Папку .venv можно не отправлять другу: она создастся сама.
